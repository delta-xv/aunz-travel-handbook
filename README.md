# 澳新旅行手册

所有设备共用手机界面，最大宽度 430px，宽屏居中展示。日期条和天气可用触摸或鼠标拖动。底部导航在有效触摸松开时切换，忽略重复的兼容点击；快速切换时同步更新页面和滚动位置，浏览器限制历史写入时改用锚点跳转。主手册与出团通知共用袋鼠、银蕨图片背景，两个图案按手机竖屏分开排列，完整缩放显示，以淡色水印和半透明内容底保持文字清晰；背景尺寸在页面打开时固定，滚动和地址栏收放不改变尺寸；屏幕宽度变化时重新适配。打印时不显示背景图。

澳大利亚、新西兰跟团旅行手册。行程：2026年9月24日—10月8日，12晚15天。

线上访问：[澳新旅行手册](https://delta-xv.github.io/aunz-travel-handbook/)。GitHub Pages 从 `main` 分支根目录自动发布。

## 浏览内容

- **今日**：当天随手查。按设备日期自动选择行程，横向日期条仅显示 D1–D15，打开页面时自动选中并定位当天日期；点击当天的 D 编号恢复自动选择，系统日期变化时也自动更新；顶部日期保持 13px，预览时显示所选日期。出发前显示 D1，结束后显示 D15。按路线与交通提醒、天气与穿衣、地点快捷入口、住宿餐食排列，不显示长段游览概述。穿衣和地点默认展开、可收起。“景点与游览安排”直接打开当天游览内容；纯交通日显示“完整安排”。
- **行程**：浏览完整的 15 天游览安排、景点简介和游览提示。进入时定位当天，出发前定位 D1，结束后定位 D15；一次在列表内展开一天。地点卡片的中文名称下方显示英文；展开一次即可阅读简介、地图和游览提示（含拍摄建议），内部不再嵌套展开或地图弹窗。交通、餐食、住宿和其他地点收在默认折叠的“当日信息”中；穿衣建议统一放在“今日”。
- **地图**：顶部仅保留一行“澳大利亚／新西兰／全程”按钮。沿途地点仅显示名称，地图统一使用圆点标记，点击查看中英文名称和关联行程，不另设字母或数字编号。先按设备日期显示当天主要行程地点，再自动获取手机位置并居中；未授权或定位失败时保留行程视图。跨城日使用主要游览地，D1、D15 及行程日期之外使用全程视图。三个按钮可恢复区域视图，定位结果不会覆盖已手动选择的视图。同一天内保留手动切换的区域，日期变化后再次进入地图会重新匹配。使用 Leaflet + OpenStreetMap 交互地图，可切换澳大利亚／新西兰，拖动、双指缩放，点击地点查看关联行程。“全程”显示上海往返澳新两国的完整路线，再次点击可关闭地点弹窗并恢复全程视野。澳大利亚／新西兰按钮聚焦对应国家，再次点击恢复该国视野。连线表示行程顺序，不代表实际道路或航线。

点击航班号直接打开 FlightAware 对应航班页面。页面可能默认显示最近一班，请核对出行日期。

航班号使用紧凑的行内标签；航班与百科链接使用导航深蓝底色与浅色文字；游览安排入口、景点展开入口及地点列表使用透明底色与描边，城市链接保留下划线；外部链接标记 ↗，页内展开项使用上下箭头，并提供按下反馈。右上角“出团通知”为与导航深蓝色一致的独立入口。

上海显示为普通文字，其他城市与没有简介的景点提供中文 Wikipedia 链接；已有简介的景点省略百科按钮。没有对应词条时，提供百科搜索或标明相关词条。

地图组件在首次展开地点卡片或进入“地图”标签时加载；每张打开的卡片独立管理地图，关闭卡片或切换行程后释放地图。底图由浏览器直接向 OpenStreetMap 请求，不经过 GitHub Pages。每次打开网页后，首次进入地图会通过浏览器请求一次定位，显示定位点和精度范围；拒绝后不反复询问，不后台跟踪、不保存坐标。定位需要 HTTPS 和系统定位服务，局域网 HTTP 地址仅支持行程地图。不预下载离线地图；按服务端缓存规则复用瓦片。底图请求失败时保留行程标记并提供重试。OpenStreetMap 公共瓦片服务不保证可用性，手机所在网络需要能访问该服务。

## 天气与手机功能

天气数据由 Open-Meteo 提供，按 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 使用；页面将天气代码译成中文、温度四舍五入，并在天气文字旁显示对应的线条图标；图标内嵌，无需额外下载，来源署名保留在温度单位的文字提示中，不提供供应商跳转入口。天气卡片统一按日期、地点、温度区间、天气图标和降雨概率排列；当天实况缩为下方一行小字。卡片内部不设分隔线或独立跳转行，点击整张卡片打开 Windy 详细天气，地点名称不再单独跳转百科。显示所选日期起四天的主要停留地预报，境外地名采用“中文(English)”格式。行程外日期使用上海，跨城日还需查看出发地天气。预报外的日期显示暂无数据；穿衣建议参考当地季节。

每次打开或回到页面时主动刷新天气，切换日期时可复用 30 分钟内的缓存，也可手动刷新。正常天气不显示缓存或更新时间；刷新失败且缓存超过 30 分钟时，仅提示“更新失败 · 上次预报”。超过 24 小时的缓存不再显示。天气时间采用地点当地时区。

点击当天地点可查看同一套地点详情：中英文名称、已有简介、可拖动缩放的地图和提示，文字可直接选择，不提供复制按钮。关闭后回到原来的行程位置。52 个地点的坐标及来源保存在 `assets/place-locations.js`，手机端不请求地点搜索服务；湖泊、公园等区域按范围展示。路线图的地点弹窗同样展示中英文名称，不提供第三方地图跳转。


返回键可关闭地图面板。每日行程在列表内展开，不使用全屏详情弹窗。原生弹窗或本地存储不可用时也可继续阅读。

## 出团通知

页眉提供唯一的“出团通知”入口。打开后先显示目录，按团队信息、航班、旅行须知、保险、每日行程、费用和自费项目组织；点击标题阅读对应小节，可返回目录或切换上一节、下一节。保留通知正文、航班表、保险和费用表，删除市场价补差段落、领队个人信息及接机牌所在行、旅客姓名和地接电话；合并 PDF 换行和跨页造成的断句，接回跨页的餐食及酒店地址。原稿中的入境物品图已逐项转为文字。联系电话仅使用 `scripts/public-contacts.json` 中列出的保险客服、救援热线与酒店公开电话，配置附公开来源；无法确认的原稿号码不发布。原 PDF 保存在仓库外，仅用作本地转换源，不随网站发布；出团通知页面不提供原稿下载入口，不加载原稿图片或 PDF。

index.html                     主手册
assets/handbook-content.js      行程、景点和穿衣说明

assets/route-map.css            地图触屏样式

## 局域网访问

在项目目录运行，将地址换成本机局域网 IP：

```sh
python3 -m http.server 48765 --bind <本机局域网IP>
```

手机连接同一局域网，访问 `http://<本机局域网IP>:48765/index.html`。服务期间电脑需保持开机且不休眠。

航班采用出团通知中的航班号，并按出行日期查询公开计划时刻。实时延误、取消和登机口以航司通知为准；集合地点、住宿与游览安排以出团通知和领队通知为准。

## 原稿转换

`python3 scripts/build-notice.py /path/to/出团通知.pdf` 使用本地的 pdfplumber 和 lxml 将原 PDF 转成 HTML。脚本识别标题并生成目录，合并连续正文和跨页续行；航班表合并为统一六列，只保留一组表头，其他表格保留原有跨行、跨列关系。先逐页校对全部非空白字符，删除领队及接机牌个人信息行、旅客姓名、地接电话、指定的市场价补差段落和 PDF 页码，并将酒店与保险电话统一为公开联系名单中的号码，最后核对其余正文字符；列表符号统一为可显示的圆点。入境物品图的清单按原图逐项转录。若 PDF 页数或表格结构变化，需要先核对脚本中的表格选择。运行前优先使用项目虚拟环境。

发布前运行 `node scripts/version-assets.mjs`，按文件内容更新 HTML 中的静态资源版本，避免浏览器沿用旧脚本。

地图使用 [Leaflet 1.9.4](https://leafletjs.com/) 和 [OpenStreetMap](https://www.openstreetmap.org/copyright)，遵守[瓦片使用政策](https://operations.osmfoundation.org/policies/tiles/)。底图地址配置在 `index.html` 的 `data-tile-url`，更换服务商时同步修改署名。

地点坐标使用 OpenStreetMap（ODbL）和 Wikidata（CC0）公开数据，逐项记录来源。坐标已预先核对并随网页提供，不在运行时批量查询或自动补全地点。
